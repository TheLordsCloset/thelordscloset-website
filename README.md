# The Lord’s Closet

A simple static website for a small 501(c)(3) thrift shop.

## Pages

- `index.html` — Home
- `about.html` — Mission, history, where profits go
- `hours.html` — Hours & contact
- `donate.html` — Donation guidelines and giving
- `blog.html` — Placeholder posts

## Preview locally

Open `index.html` in a browser, or from this folder run:

```bash
python -m http.server 8080
```

Then visit http://localhost:8080
